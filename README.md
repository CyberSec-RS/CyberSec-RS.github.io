## Sobre este repositorio
Este repositorio contiene la versión pública del CV interactivo de Rosendo Santos. La página está optimizada para reclutadores y para generar un PDF con formato A4 desde el propio navegador.

La intención es ofrecer una «tarjeta de presentación» profesional, clara y fácil de revisar por humanos y por sistemas de preselección (ATS).

## Uso rápido
- `index.html` — Página principal del CV (visual, semántico y ATS-friendly).
- `style.css` — Estilos para una presentación limpia y profesional.
- `script.js` — Funcionalidad para descargar el CV como PDF y opción de impresión.

Para ver la página en vivo: espera a que GitHub Pages publique y abre https://CyberSec-RS.github.io

## Cómo obtener el PDF
En la página principal, usa el botón **"Descargar PDF"** para generar y descargar una versión imprimible en A4 (se genera localmente en tu navegador). Alternativamente, usa el diálogo de impresión del navegador: `Archivo → Imprimir → Guardar como PDF`.
